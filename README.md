# flow-trail

A simple workflow tool for use in my everyday. Allows users to create projects(Kanban boards) and keep track of them through tasks. I use this to keep track of everything I want to get done.

Features:
- Collaborative projects that allow users to invite other members to collaborate
- Utilizes Laravel Reverb and Echo to allow users to chat with other online project members over websockets
- Used this project as a way to learn more about events, listeners and websockets in Laravel

Tech Stack: Laravel, React (Typescript), InertiaJs, dndkit for creating a drag and drop.
